Live Clipper

A personal tool that turns live-stream highlights into short vertical clips.

Live Clipper is a private, single-user application run by the owner of the ShortCircuitVibes YouTube channel. It watches public live streams, finds the moments viewers react to most, edits them into short vertical videos with captions and a credit to the original streamer, and uploads them to the owner's own YouTube channel.

How it uses YouTube

  • Uploads finished clips to the owner's own channel through the YouTube Data API.
  • Reads the status of those uploads to detect videos that were rejected or removed.
  • It does not access, collect or store data about any other YouTube user.

Every clip credits the original creator by name and platform.
